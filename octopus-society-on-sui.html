Overview

Tutorial sample · Fictional Move package

This tutorial demonstrates an end-to-end workflow for joining Octopus Society, a fictional membership module built with Move on Sui. The package ID, object IDs, and example data are provided to illustrate structure, flow, and documentation style.

By the end of the tutorial, you will have connected a wallet, minted a membership object, verified ownership on-chain, and claimed a reward tied to that membership.

Preparation

Before you start

The setup section establishes the environment, credentials, and tooling needed before the membership flow begins.

Requirements and setup

Environment · Wallet · Request tooling

Before you begin, make sure you have:

    >The Sui CLI installed and configured for an active environment, such as testnet. >A wallet address with test SUI for gas, funded through a testnet faucet. >Node.js and the de>@mysten/sui.js package if you plan to use the TypeScript examples. >The package ID for the Octopus Society Move module.

In the examples below, replace de>{package_id} and de>{my_address} with your own values. In a real application, you would typically store them in environment variables such as de>PACKAGE_ID and de>ACTIVE_ADDRESS.

For safety, use a testnet environment while testing this workflow.

Active environment and gas

Network and gas budget

All examples in this tutorial target testnet and use an explicit gas budget.

de>sui client active-address
sui client gas

Confirm your active address holds enough gas before minting or transferring objects. In a real implementation, handle transaction failures explicitly and surface clear error messages when gas is insufficient.

Reference

Object model

The tutorial introduces the membership object before the task sequence so the later examples stay predictable and easy to follow.

Membership object

Field reference

The tutorial uses a single de>Membership object with the following fields:

Field Type Set by Description
de>id UID Module Unique object ID generated when the membership is minted.
de>member address Module Address that owns the membership object.
de>tier u8 Caller Membership tier selected when joining.
de>joined_at u64 Module Epoch timestamp recorded when the membership is created.

Module snapshot

Function overview

    >de>join(tier: u8) — Mints a new de>Membership object for the caller. >de>verify_membership(membership: &Membership) — Reads membership fields without modifying state. >de>claim_reward(membership: &Membership) — Emits a reward event for an existing member.

The tutorial uses one membership per address. Calling de>join again with the same address creates a separate object rather than replacing the existing one.

Workflow

Membership tutorial

Each step keeps the task sequence explicit and lets the reader switch between the Sui CLI and TypeScript without losing context.

1. Connect the wallet

Check the active address and balance

de>sui client active-address
sui client switch --address {my_address}
de>import { SuiClient, getFullnodeUrl } from "@mysten/sui.js/client";

const client = new SuiClient({ url: getFullnodeUrl("testnet") });

const address = "{my_address}";
const balance = await client.getBalance({ owner: address });

The client confirms the active address and gas balance before any transaction is submitted.

2. Join Octopus Society

Mint a membership object

de>sui client call \
  --package {package_id} \
  --module octopus_society \
  --function join \
  --args 1 \
  --gas-budget 10000000
