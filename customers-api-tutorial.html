Overview

A compact API onboarding flow

This sample is designed as an onboarding tutorial for developers who need one complete workflow before moving on to broader API reference material.

Scenario

Tutorial framing · first-use workflow

The tutorial follows a single customer record through a full lifecycle. This keeps the reader focused on one resource, one sequence, and one clear success outcome.

The API in this example is fictional. The structure, pacing, and explanation style are intended to demonstrate how I write task-based developer documentation.

Preparation

Before you start

The setup section defines what the user needs before sending a first request and reduces ambiguity around environment, access, and tooling.

Requirements

Environment · access · request tooling

  • An API access token with permission to use the Customers API.
  • The base URL for the target environment, such as sandbox or production.
  • A tool for sending HTTP requests, such as curl or Postman.
  • Basic familiarity with JSON request and response payloads.

Replace placeholder values such as {base_url} and {access_token} with your own values before running the examples.

Authentication headers

Bearer token authentication

All requests in this tutorial use bearer token authentication and JSON where a request body is required. 

Authorization: Bearer {access_token}
Content-Type: application/json

Workflow

Customer lifecycle tutorial

Each step pairs explanatory context with switchable code examples so readers can compare request styles without leaving the flow.

1. Create a customer

POST /api/1.0/customers

Use a POST request to create a new customer record. The response returns a permanent id that you use in later requests. 

curl -X POST "{base_url}/api/1.0/customers" \
-H "Authorization: Bearer {access_token}" \
-H "Content-Type: application/json" \
-d '{
  "full_name": "John Doe",
  "email": "john@doe.com"
}'
const response = await fetch(`${baseUrl}/api/1.0/customers`, {
  method: "POST",
  headers: {
    Authorization: `Bearer ${accessToken}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    full_name: "John Doe",
    email: "john@doe.com"
  })
});

const customer = await response.json();

Example response:

{
  "id": "9c7c97a8-ac45-bh78-8b38-26a74fdf1fgh",
  "full_name": "John Doe",
  "email": "john@doe.com",
  "created_at": "2022-06-13T12:03:39.979397Z",
  "updated_at": "2022-06-13T12:03:39.979397Z"
}

2. Retrieve a customer

GET /api/1.0/customers/{id}

Use a GET request to retrieve the customer record by using the id returned in the previous step. 

curl "{base_url}/api/1.0/customers/{id}" \
-H "Authorization: Bearer {access_token}"
const response = await fetch(`${baseUrl}/api/1.0/customers/${customer.id}`, {
  headers: {
    Authorization: `Bearer ${accessToken}`
  }
});

const customerDetails = await response.json();

Example response:

{
  "id": "9c7c97a8-ac45-bh78-8b38-26a74fdf1fgh",
  "full_name": "John Doe",
  "email": "john@doe.com",
  "created_at": "2022-06-13T12:03:39.979397Z",
  "updated_at": "2022-06-13T12:03:39.979397Z"
}

3. Update a customer

PATCH /api/1.0/customers/{id}

Use a PATCH request to update selected fields on an existing customer record. 

curl -X PATCH "{base_url}/api/1.0/customers/{id}" \
-H "Authorization: Bearer {access_token}" \
-H "Content-Type: application/json" \
-d '{
  "email": "john.doe@newdomain.com"
}'
const response = await fetch(`${baseUrl}/api/1.0/customers/${customer.id}`, {
  method: "PATCH",
  headers: {
    Authorization: `Bearer ${accessToken}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    email: "john.doe@newdomain.com"
  })
});

const updatedCustomer = await response.json();

Example response:

{
  "id": "9c7c97a8-ac45-bh78-8b38-26a74fdf1fgh",
  "full_name": "John Doe",
  "email": "john.doe@newdomain.com",
  "created_at": "2022-06-13T12:03:39.979397Z",
  "updated_at": "2022-06-13T12:14:04.321890Z"
}

4. Delete a customer

DELETE /api/1.0/customers/{id}

Use a DELETE request to remove the resource after the workflow is complete. 

curl -X DELETE "{base_url}/api/1.0/customers/{id}" \
-H "Authorization: Bearer {access_token}"
await fetch(`${baseUrl}/api/1.0/customers/${customer.id}`, {
  method: "DELETE",
  headers: {
    Authorization: `Bearer ${accessToken}`
  }
});

Example response:

{
  "status": "deleted",
  "id": "9c7c97a8-ac45-bh78-8b38-26a74fdf1fgh"
}
