Context

Overview

What this tutorial covers

Sample content · Fictional API

This tutorial demonstrates a simple end-to-end workflow for managing customer data with the Customers API. The API, URLs, and example data are fictional and are provided only to illustrate structure, flow, and writing style.

In the following steps, you create, retrieve, update, and delete a customer record by using the /api/1.0/customers endpoint and the permanent customer id returned by the API.

Preparation

Before you start

The tutorial assumes a standard API workflow with authentication, environment-specific base URLs, and a tool for testing requests.

Requirements

Access · Environment · Request tooling

Before you begin, make sure you have:

  • An API access token with permission to call the Customers API.
  • The base URL for your environment, for example sandbox or production.
  • A tool for sending HTTP requests, such as curl or Postman.
  • Network access to the /api/1.0/customers endpoint.

In the examples below, replace {base_url} and {access_token} with your own values.

Workflow

Customer lifecycle tutorial

The sequence below follows a simple CRUD flow so developers can understand how a customer record is created and then reused in later requests.

1. Create a customer

POST /api/1.0/customers

Use a POST request to create a new customer record. The response returns a permanent id that you use in later requests. 

curl -X POST "{base_url}/api/1.0/customers" \
-H "Authorization: Bearer {access_token}" \
-H "Content-Type: application/json" \
-d '{
  "full_name": "John Doe",
  "email": "john@doe.com"
}'
const response = await fetch(`${baseUrl}/api/1.0/customers`, {
  method: "POST",
  headers: {
    Authorization: `Bearer ${accessToken}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    full_name: "John Doe",
    email: "john@doe.com"
  })
});
const customer = await response.json();

Example response:

{
  "id": "9c7c97a8-ac45-bh78-8b38-26a74fdf1fgh",
  "full_name": "John Doe",
  "email": "john@doe.com",
  "created_at": "2022-06-13T12:03:39.979397Z",
  "updated_at": "2022-06-13T12:03:39.979397Z"
}

2. Retrieve a customer

GET /api/1.0/customers/{id}

Use a GET request to retrieve the customer record by using the id returned in the previous step. 

curl "{base_url}/api/1.0/customers/{id}" \
-H "Authorization: Bearer {access_token}"
const response = await fetch(`${baseUrl}/api/1.0/customers/${customer.id}`, {
  headers: {
    Authorization: `Bearer ${accessToken}`
  }
});
const customerDetails = await response.json();

Example response:

{
  "id": "9c7c97a8-ac45-bh78-8b38-26a74fdf1fgh",
  "full_name": "John Doe",
  "email": "john@doe.com",
  "created_at": "2022-06-13T12:03:39.979397Z",
  "updated_at": "2022-06-13T12:03:39.979397Z"
}

3. Update a customer

PATCH /api/1.0/customers/{id}

Use a PATCH request to update selected fields on an existing customer record. 

curl -X PATCH "{base_url}/api/1.0/customers/{id}" \
-H "Authorization: Bearer {access_token}" \
-H "Content-Type: application/json" \
-d '{
  "full_name": "Johnathan Doe"
}'
const response = await fetch(`${baseUrl}/api/1.0/customers/${customer.id}`, {
  method: "PATCH",
  headers: {
    Authorization: `Bearer ${accessToken}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    full_name: "Johnathan Doe"
  })
});
const updatedCustomer = await response.json();

Example response:

{
  "id": "9c7c97a8-ac45-bh78-8b38-26a74fdf1fgh",
  "full_name": "Johnathan Doe",
  "email": "john@doe.com",
  "created_at": "2022-06-13T12:03:39.979397Z",
  "updated_at": "2022-06-13T12:16:11.103004Z"
}

4. Delete a customer

DELETE /api/1.0/customers/{id}

Use a DELETE request to remove the customer record when you no longer need it. 

curl -X DELETE "{base_url}/api/1.0/customers/{id}" \
-H "Authorization: Bearer {access_token}"
await fetch(`${baseUrl}/api/1.0/customers/${customer.id}`, {
  method: "DELETE",
  headers: {
    Authorization: `Bearer ${accessToken}`
  }
});

Example response:

{
  "status": "deleted",
  "id": "9c7c97a8-ac45-bh78-8b38-26a74fdf1fgh"
}
